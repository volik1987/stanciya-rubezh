# Защита станции

Tower defense про оборону космической станции: 16 типов башен, 30+ видов чужих, экономика жилого квартала, энергетика, лаборатория и дерево технологий. 100 волн и бесконечный режим.

Играть: https://volik1987.github.io/stanciya-rubezh/

Игра — PWA: её можно установить на телефон, планшет или компьютер и играть без интернета. Сохранения и рекорды хранятся на устройстве.

## Обновление

После правок `index.html` или картинок пересоберите офлайн-кэш, иначе установленные копии не получат новые файлы:

```
python3 make-sw.py
```
